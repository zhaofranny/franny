# Franny v0.2 · 邪修减肥大法原创图文工作台

面向创作者的 Python 3.12 + Streamlit + SQLite 工作台：合法CSV元数据分析 → 在线原创 → 编辑 → 健康证据核对 → 原创中文PNG字卡 → 本地素材包。`邪修`是幽默反差栏目包装，内容聚焦省力健康习惯，不承诺减重结果或保证爆款。

## 运行

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

本机启动后访问 http://localhost:8501 。云端必须使用托管平台生成的域名，见 `DEPLOYMENT.md`。

Linux中文字体：`packages.txt` 声明 `fonts-noto-cjk`，Streamlit Community Cloud会安装该系统包。本地也可设置 `CJK_FONT_PATH` 指向你有权使用的中文TTF/TTC/OTF文件。字体缺失会明确报错，不输出乱码图。

## 正式创作流程

1. **在线生成默认开启。** 侧栏输入自己的OpenAI API Key（会话内使用），或者配置服务器密钥与访问口令。没有密钥按钮禁用，不以模板充当AI生成。需要允许 `api.openai.com:443` 出站访问。模型默认 `gpt-4o-mini`，支持JSON输出即可，费用由服务商计收。
2. 栏目选择 `邪修减肥大法 · 省力习惯派`、`外卖党 · 搭配派` 或 `上班族 · 碎片活动派`，选择/输入选题与人群。
3. 点击“生成原创草稿”：一次返回主标题、至少3个备选标题、正文、标签、至少3张图文卡片、健康主张引用线索及原创插画提示词。无数据也可独立创作；有合法数据时只使用聚合分析。
4. 编辑最终标题、正文、标签、卡片JSON；保存修改后重新检查，并清除审核状态与旧图片。备选标题是生成时的灵感，改稿后需要重新判断是否适用。
5. 对照WHO/CDC原文核对所有正文与图片的健康表述。`claims` 是模型提出的逐句引用线索，不保证证据充分或覆盖完整。改写/删除原句会移除失效映射，需要重新人工核对。
6. 点击“生成原创封面和配图 PNG”：本地排版1080×1440中文原创字卡，支持奶油绿/黑金配色，不消耗图片模型费用。它是排版卡片，不是AI绘画；AI插画接口仍预留。
7. 填写审核人、逐条核对记录，勾选核对后确认。只有在线生成、当前内容经过人工确认且已有图片时，才显示“下载正式发布素材包”。审核只是编辑声明，不表示医学正确或平台审核通过。
8. ZIP包含 `publish.txt`、`images/*.png`、`draft.md`、`draft.json`、`image_prompts.json`、`REVIEW.txt`。将PNG与文案上传小红书官方创作平台预览后发布。**未接入自动发布API**。

离线模式需手动开启，仅供界面/风格演示，带示例标识，不能通过正式审核。仍可下载待审核示例素材包。

## 云端密钥与访问控制

在Streamlit应用管理的Secrets中设置（不要将真实值提交Git或发到聊天）：

```toml
OPENAI_API_KEY = "你的服务商密钥"
OPENAI_MODEL = "gpt-4o-mini"
APP_PASSWORD = "你自己设置的强访问口令"
```

服务器密钥只有配置 `APP_PASSWORD` 后才启用；否则必须使用访客自己的会话密钥。访问口令配置后，先登录才能读取数据库和生成素材。单个口令面向同一创作者/可信小团队，没有多用户角色、审计身份认证或暴力破解防护；审核人是手动填写的声明。公开实例中的数据库与素材库可能被所有访客看到，不要在开放实例上传私有数据。

SQLite与素材历史存在部署服务本地磁盘。Community Cloud重启/休眠/重部署后可能丢失；真实业务应使用持久磁盘并备份。不应将v0.2描述为已经满足企业多租户生产要求。

## 数据契约与评分

CSV为UTF-8或UTF-8 BOM，1–50000行、最多10MB。中英文列名均支持：

| 英文列 | 中文列 | 约束 |
| --- | --- | --- |
| title | 标题 | 必填，最长500字 |
| url | 笔记链接 | 小红书域名HTTPS，不请求链接 |
| published_at | 发布时间 | 无时区按北京时间，拒绝未来时间 |
| likes | 点赞数 | 0至10^12整数 |
| saves | 收藏数 | 同上 |
| comments | 评论数 | 同上 |

全批校验后事务写入。URL去掉查询参数/片段/末尾斜杠，重复导入覆盖最新互动数；短链接与完整链接不自动合并。`examples/notes.csv` 的标题、链接和互动数全为虚构，不用于声称真实热度。

评分：`100 × (1 − exp(−ln(1+点赞+2×收藏+3×评论)/8)) × 0.5^(发布天数/半衰期)`，默认半衰期30天。支持总互动、日期、字面关键词筛选和多种降序排序。它是启发式样本排序，没有曝光数据，不计算真实互动率，不预测爆款。

标题规则推断数字清单、提问、场景与误区结构，主题/痛点是标题假设，不代表正文分析或用户研究。

## 健康、原创与证据边界

模型仅接收输入选题、人群、栏目、聚合分析及静态证据，不接收原笔记标题/链接/正文/图片。生成提示限制虚构效果、亲测经历、危险偏方和身材对比。Pydantic验证长度/结构，引用ID必须存在，claims必须逐字对应正文并指向已选来源。原创是创作目标，未执行互联网全库查重。

`health.py`阻断明显的极端节食、脱水掉秤、催吐、泻药/利尿剂、局部减脂和保证效果。规则可能误报或漏检，不能取代医学事实核查。内置来源是WHO健康饮食、WHO身体活动和CDC体重管理，未经实时检索；给定来源ID不代表每句成立。所有内容必须由编辑自行核对完整原文、适用范围与风险。

未成年人、孕哺期、有疾病或进食困扰者不提供减重处方；实际饮食/活动安排须根据个人情况咨询合格专业人士。系统不使用未经授权的采集或发布接口。

## 测试与文件

```bash
python -m pytest -q
pip check
```

`app.py` 为界面；`franny/`包含导入持久化、分析、生成、健康检查、编辑审核、PNG排版、配置和导出模块。`tests/`覆盖数据、模拟OpenAI契约、危险内容、审核失效、PNG、素材导出和Streamlit完整交互。`TEST_RESULTS.md`记录实际检查。

`requirements.txt`声明依赖范围，`requirements.lock.txt`记录原环境精确版本。`packages.txt`用于云端字体。在线模型质量与计费路径仍需部署者使用自己的有效密钥验证；测试模拟成功不代表真实API已调用。

## v0.2.1 生成失败排查

失败时页面显示允许公开的错误分类，不显示原始API错误体、密钥或输入正文：

- `API_AUTH_401`：替换有效的完整API密钥，确认并非ChatGPT登录密码。
- `API_QUOTA_429`：检查API Billing、项目预算和余额，ChatGPT订阅不包含API额度。
- `API_RATE_429`：查看用量限制，避免连续重试。
- `API_PERMISSION_403` / `API_MODEL_404`：核对提供商支持范围、项目权限与模型名称。
- `API_CONNECTION` / `API_TIMEOUT`：检查部署服务器到api.openai.com的网络。
- `OUTPUT_VALIDATION` / `OUTPUT_INCOMPLETE` / `CONTENT_CHECK`：模型输出长度、格式、完整性或证据对齐失败，换具体选题重试，不意味着密钥失效。

错误分类不能替代服务商账单/权限后台的具体诊断。刷新后应看到v0.2.1；有必要时在托管平台Reboot。
