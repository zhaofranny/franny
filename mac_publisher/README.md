# Franny · Mac本地图文发布最小版

这版只做单账号、单篇发布。保留现有线上系统及数据库，发布工具在自己的.local目录中存储登录浏览器、防重复记录。没有自动采集、批量发布、破解验证码、隐藏自动化特征或私有API签名。

## 启动

1. 将本文件夹放到你的Mac，确保已安装Python 3.10+（推荐3.12）。
2. 双击 `start.command`。首次安装依赖和Chromium会下载文件，之后复用，不需要Docker或模型API Key。
3. 如果不能双击，在终端进入这个文件夹执行 `bash start.command`。
4. 本地网页打开后，在“① 登录账号”打开独立浏览器，手动登录。核对显示的账号是你自己的目标账号。
5. “② 预览与发布”导入现有Franny的素材ZIP（需要含PNG），或手动输入文案并上传原创图片。点“生成本地预览”，核对图片顺序、文字、账号和真实AI声明。
6. 确认健康核查、素材权利和平台允许范围后，点“确认并发布到小红书”。后续自动操作浏览器，记录见“③ 发布记录”。

不要关闭发布浏览器，不要同时从其他进程使用同一专用配置，不要把.local、worker.log或浏览器会话交给第三方。工作台仅监听127.0.0.1，不开放公网，不提供浏览器远程调试端口。

## 实际完成的功能

- 支持手工素材和原Franny ZIP的本地导入；路径越界/符号链接/重复图片/素材变更/高风险文案检查。
- 用普通Playwright浏览器，在官方创作者页面上传图片、填写标题正文、选择话题和核对AI声明。
- 检查已登录的显示名与绑定账号一致。显示名不是官方不可变用户ID：本版本只面向单账号专用浏览器，不适合多账号自动切换。
- 同一账号+素材哈希只建一个任务。点击前先持久化submitting，点击后超时或结果不明不会自动再发。
- 只有笔记管理页中出现之前没有的笔记ID、匹配标题及明确状态，才记录已发布/审核中；只点击按钮不算发布成功。
- 提交前页面截图与任务结果在本机output目录中。不写出Cookie或登录凭据。

## 必须说明的限制

当前开发环境是Linux云端，并且不允许访问creator.xiaohongshu.com，无法替你在Mac或真实账号上完成发布验收。**没有发布过任何真实笔记，也不保证平台当前DOM选择器已适配你的账号。**

若平台改版、无法核验图片/话题/AI声明/账号，工具会停止，显示具体步骤；不会删除页面弹层、绕过验证、把失败写成成功。选择器位于xhs_publisher/config.py，可在项目根目录selectors.json中仅覆盖相应CSS列表。尤其AI声明与话题关联控件，必须按当前真实页面验证后才能提交。

官方API权限与浏览器自动化是不同路线；开源可实现不等于获得平台许可。仅在你确认当前平台规则允许的范围内使用。需要人工登录/验证时由你自行操作。

首次登录最多等待180秒。任务进入submitting、unknown、submitted_unverified、pending_review后不会自动重发；先在官方平台核对结果。进程异常退出时仍保留记录，不要为了重发而删除数据库。当前最小版没有自动回查历史不明任务或定时批量发布。

网页“已发布”不代表健康事实或平台审核永久通过；健康扫描可能误报/漏检，人工核查不能省略。
